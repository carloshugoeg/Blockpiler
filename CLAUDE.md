# CompileFlow — Agent Protocol

## Before any task
1. Read `compileflow.specs.md` fully.
2. Read `TASKS.md` fully.
3. Read the assigned task in detail.
4. Implement **exactly** what the spec says — no inventions, no simplifications.

## After completing any task — MANDATORY
1. Go to the task's section in `TASKS.md`.
2. Read the **Done Criteria** section in full.
3. Verify **each criterion** one by one — run tests, check outputs, verify signatures.
4. Verify the **Universal Pre-Commit Checklist** passes.
5. Only flip `- [ ] TNN completa` → `- [x] TNN completa` when **all** items pass.
6. If any item fails, continue working. Do not mark the task complete.
